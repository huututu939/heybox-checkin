## 盒签 v1.8.0

### 新增

- 记录页支持 90 天历史，顶部按月份切换，H 币走势也拉长到 90 天

- 设置里新增「导出签到记录」，生成 CSV 走系统分享，Excel 打开不乱码

- 设置里新增「运行自检」，一次检查权限、闹钟、看门狗、设备令牌与接口连通

### 优化

- 失败后当晚还能再补一次：常规重试用完、窗口也过了，网络恢复后仍会尝试

- 换时区或手动改时间后自动重排闹钟，不会落回已经过点的窗口

- 登录过期通知可以直接跳到登录页，不再给注定失败的「重试」

- 4×1 小组件在连续签到两天以上时显示「连续 N 天」

### 安装

下载 `app-release.apk` 覆盖安装；1.4.x 起的版本签名相同，无需卸载。

### 校验

SHA-256 见附件 `app-release.apk.sha256`。
