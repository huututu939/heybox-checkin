## 盒签 v1.7.0

### 新增

- 记录页顶部加回顾卡：连续签到天数、本月完成天数、分享任务成功率

- 每月日历上方显示当月完成 / 跳过 / 失败天数，以及 H 币月增量

### 优化

- 闹钟被系统清掉也能当天补上：窗口结束后 10 分钟自动检查，没签就补一次

- 每 4 小时检查一次闹钟是否还在，丢失就重新排；重启、覆盖安装后自动恢复

- 记录页的月度统计改成分行排版，大字体下不再挤在一起

### 安装

下载 `app-release.apk` 覆盖安装；1.4.x 起的版本签名相同，无需卸载。

### 校验

SHA-256 见附件 `app-release.apk.sha256`。
