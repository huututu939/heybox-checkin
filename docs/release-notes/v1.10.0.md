## 盒签 v1.10.0

### 新增

- 记录页覆盖一整年：365 天历史，月份胶囊可切十三个月

- 月份副标题给出漏签原因分布，失败按分类归并，整天没跑的空档单独计数

- 连续签到显示下一个里程碑（7 / 30 / 90 / 180 / 365 天）还差几天

- 「导出备份」生成 JSON 文件，「导入备份」换机或清数据后一键恢复记录

- 每次签到后自动备份历史到 Documents/盒签/盒签备份.json，同一文件覆盖写

### 优化

- 通知加两个开关：签到成功后通知可关；夜间静音（22:00 – 次日 8:00）只压成功通知，失败与连续漏签照常提醒

- 运行自检补「自启动 / 后台清理」条目：ROM 管理策略探测不到就明说，并给出手动设置路径

### 安装

下载 `app-release.apk` 覆盖安装；1.4.x 起的版本签名相同，无需卸载。

### 校验

SHA-256 见附件 `app-release.apk.sha256`。
