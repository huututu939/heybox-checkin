## 盒签 v1.4.2

### 新增

- 关于页新增「检查更新」，对比 GitHub 最新 Release；登录失败与版本相关时（如官方设备令牌组件升级），登录页直接给出下载入口

- 值守条件新增「最近任务隐藏」，开启后离开 App 结束任务，多任务中不保留卡片

### 修复

- 跨天后重新打开 App 仍显示前一天的完成状态与增量，出现「今日待执行」与「已由其它入口完成」并存

- 检查更新失败时，较长的错误文案将「打开下载页」挤出屏幕；失败状态补充「重试」

### 安装

下载 `app-release.apk` 覆盖安装；已装 1.4.x 可直接升级，签名相同。

### 校验

SHA-256 见附件 `app-release.apk.sha256`。
