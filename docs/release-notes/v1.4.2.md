## 盒签 v1.4.2

三处改动，都是围绕「用久了不出岔子」。

### 新增

- **检查更新**：关于页「版本」卡里多了「检查更新」，会对比 GitHub 上的最新 Release。登录失败如果和版本有关（比如官方设备令牌组件升级），登录页会直接给出下载入口，不用再猜是不是账号问题
- **最近任务隐藏**：值守条件里新增开关，开启后离开 App 会结束任务，多任务里不再留下盒签卡片。开启前请先在最近任务里长按盒签卡片锁定——没锁定时卡片直接消失，系统可能连带回收进程

### 修复

- **跨天状态不刷新**：过完一天后再打开 App，首页仍显示前一天的完成态和增量，出现「今天是待执行、卡片却说已由其它入口完成」的自相矛盾。现在只有同一天的记录才算「今天」，昨天的记录只作为「上次同步」展示
- 检查更新失败时，较长的错误文案会把「打开下载页」挤出屏幕；失败状态补了「重试」

### 安装

1. 下载 `app-release.apk`
2. 允许「安装未知来源应用」后侧载
3. 已装 1.4.x 的用户可直接覆盖升级（签名相同，无需卸载）

从 debug 包换过来需要先卸载，会丢登录态与历史。

### 校验

下载后对照 `app-release.apk.sha256` 里的 SHA-256 与文件哈希即可。
