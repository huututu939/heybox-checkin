## 盒签 v1.5.1

### 新增

- 首页拆分为「今天 / 设置」两个页签：状态、今日到账、下次执行窗口、每日四件、最近七天收入一屏

- 「立即执行一次」移入「今天」页签，不再与底栏挤在一起

- 记录页：展示最近七天完成、跳过、未执行情况与当天经验、H 币、电池增量

- 设置页按自动、值守、显示、其他分组；值守条件用状态点标识，权限未开启时提供「去设置」

- 明暗两套配色：白天暖白配琥珀，夜间深灰配暖橙，可跟随系统或手动指定

- 液态玻璃界面：背景光斑、半透明卡片与悬浮底栏，含后景模糊、边缘折射与上沿高光

- 底栏支持横向拖动切换：跟手阻尼，松手按位置与速度吸附到最近页签；按下时玻璃珠放大并出现色散

### 修复

- 底栏出现「两个框」：描边与未裁齐的反光叠加，现只保留选中块轮廓

- 「今天 / 设置」文字被底栏高度裁掉一半

- 点击页签后又被抬手动作吸附回旧页签

- 底栏仅采样页面内容、空白处透明，导致玻璃发灰

### 安装

下载 `app-release.apk` 覆盖安装；1.4.x 签名相同，登录态与历史保留。

### 校验

SHA-256 见附件 `app-release.apk.sha256`。
