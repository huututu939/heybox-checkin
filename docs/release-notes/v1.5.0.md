## 盒签 v1.5.0

界面整套重做，功能还是那四件事。

### 新界面

- **今天 / 设置 两个页签**：状态、今日到账、下次执行窗口、每日四件、最近七天收在一屏；「立即执行一次」也回到「今天」页，不再和底栏挤在一起
- **记录页**：最近七天逐条列完成、跳过、没执行，以及当天的经验 / H 币 / 电池增量
- **设置分组**：自动、值守、显示、其他。值守条件用圆点标状态，权限没开的直接给「去设置」
- **明暗两套配色**：白天是暖白底配琥珀强调色，夜间是深灰底配暖橙，切换跟随系统或在「显示」里手动指定

### 液态玻璃

- 背景铺一层柔和光斑，卡片、底栏都是半透明玻璃：后景模糊 + 边缘折射 + 上沿高光，卡片还带一点暖到紫的表面色相
- 底栏是悬浮的玻璃胶囊，离屏幕底部留了距离；选中块是一颗会动的玻璃珠
- **拖动切换**：横拖跟手、带阻尼，松手按位置和速度吸附到最近的页签；按下时玻璃珠放大并出现色散，同时有一团高光跟着手指

### 修复

- 底栏之前会看到「两个框」（一层描边 + 一层没裁齐的反光），现在只留选中块那一圈椭圆
- 「今天 / 设置」文字被底栏高度裁掉一半
- 点页签后又被抬手动作吸附回旧页签
- 底栏只采样页面内容、空白处透明，导致玻璃发灰

### 安装

1. 下载 `app-release.apk`
2. 允许「安装未知来源应用」后侧载
3. 已装 1.4.x 的用户可直接覆盖升级（签名相同，登录态与历史都在）

### 校验

```text
SHA-256: 见 Release 附件 app-release.apk.sha256
```
