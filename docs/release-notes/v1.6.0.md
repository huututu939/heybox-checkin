## 盒签 v1.6.0

### 新增

- 失败原因分类：网络、服务、登录、验证、限流、核对六类，通知和记录页直接说明原因与下一步

- 连续漏签提醒：连续 2 天没签上（包括整天没有记录）时发一条会响的通知，首页同步显示提示条

- 记录页月历：按月展示签到状态，点选日期查看当天执行时间与到账明细

- 余额走势：记录页顶部显示最近 30 天 H 币余额曲线

### 优化

- 登录过期的提示条直接提供「重新登录」入口

- 人机验证类失败不再占用当天的自动重试次数

- 自动检查更新改为成功间隔 12 小时、失败间隔 1 小时，避免触发 GitHub 接口限流

- 首页区块间距收紧，一屏信息密度更高

### 修复

- 首页出现提示条时，「立即执行一次」按钮被悬浮底栏遮挡

### 安装

下载 `app-release.apk` 覆盖安装；1.4.x / 1.5.x 签名相同，无需卸载。

### 校验

SHA-256 见附件 `app-release.apk.sha256`。
