## 盒签 v1.6.0

这版解决的问题只有一个：**没签上时，你得知道为什么、要不要管**。顺带把记录页换成了一眼能看懂的月历。

### 没签上，不再是「一条失败通知」了

- **失败分成六类**：网络 / 服务 / 登录 / 验证 / 限流 / 核对。通知和记录页会直接说是哪一类，并给一句下一步该做什么
- **要人机验证就明说**：这类失败自动重试永远过不去，所以不再浪费当天的重试次数，提示你手动去签一次
- **连续没签上会响**：连着 2 天以上没成功（包括「整天没有记录」——闹钟没响也在这类），会走单独的「连续失败提醒」通道，不再是无声通知，首页顶部也会出一条提示
- **登录类失败给「重新登录」**：不用先去记录页猜原因

### 记录页：从 30 行列表换成月历

- 一个月一张卡，周一在首列，**颜色就是状态**：绿=完成、灰=其它入口已完成、红=失败，空格=没记录
- 点任意一天，下面显示那天的时间和到账（经验 / H 币 / 电池），失败的那天给原因
- 顶部加 30 天 H 币余额走势：余额单调，断签一眼就能看出来

### 顺手修的

- 自动检查更新改成「成功等 12 小时、失败等 1 小时」：之前每次打开都查一次，GitHub 未认证接口 60 次/小时，开关几次就可能被限流
- 首页区块间距收紧，出现提示条时「立即执行一次」也不会被悬浮底栏压住

### 安装

1. 下载 `app-release.apk`，或在 1.5.x 的 App 里点「检查更新」
2. 1.4.x / 1.5.x 可直接覆盖，签名相同

### 校验

```text
SHA-256: 见 Release 附件 app-release.apk.sha256
```
