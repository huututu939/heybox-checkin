## 盒签 v1.6.1

### 修复

- 应用内更新弹窗把多条更新说明拼成一段长文，现只显示第一条改动，完整清单在 Release 页面
- 更新说明超长被截断时，末尾补省略号

### 优化

- 发版说明改为按「新增 / 优化 / 修复」分条，一条一件事，应用内弹窗取第一条作为预览

### 安装

下载 `app-release.apk` 覆盖安装；1.4.x / 1.5.x / 1.6.0 签名相同，无需卸载。

### 校验

SHA-256 见附件 `app-release.apk.sha256`。
