## 盒签 v1.5.3

这一版把「记录、更新、换机」几件平时会碰到的事补完整了。

### 记录

- 历史保留 **30 天**（原来只有 8 天），记录页按月分组，头部有完成 / 跳过 / 失败统计
- **失败会留原因**：「登录已过期」「HTTP 500」直接写在当天那一行，首页状态也会显示「今日失败」
- 小组件在失败时显示原因，不用打开 App 才知道为什么没签上

### 更新

- 弹窗里能看到**更新包大小**、**这一版改了什么**，用移动网络时提醒先连 WiFi
- 新增「**跳过这个版本**」：跳过后同一个版本不再每天弹，出新的再提示
- 下载完会核对 Release 附带的 **SHA-256**（拿不到校验文件就跳过这一步，签名校验仍然在）
- 镜像列表改成**可远程更新**：某条加速线路失效，不用等新版本

### 换机 / 首次使用

- 设置 → 其他 里新增「**导出配置 / 导入配置**」：定时窗口、分享开关、最近任务隐藏、外观打包成一段文本，复制到另一台机器粘贴即可。不含账号、密钥和设备标识
- 首次进首页时，如果有权限没开，会提醒一次并给「去设置」入口，之后不再打扰

### 修复

- 系统字体放大到 2 倍时，首页任务卡片的「已完成」会被裁掉半行、日期换行把状态挤歪；现在卡片跟着字体长高，标题超长会省略
- 登录页原先写死「这台机器没有卡」，对插卡的手机是错的，改成「如果这台机器没插卡」的说法

### 安装

1. 下载 `app-release.apk`
2. 允许「安装未知来源应用」后侧载；也可以直接在 1.5.2 的 App 里点「检查更新」
3. 1.4.x / 1.5.x 可直接覆盖，签名相同

### 校验

```text
SHA-256: 见 Release 附件 app-release.apk.sha256
```
