## 盒签 v1.5.3

### 新增

- 历史记录保留 30 天（原为 8 天），记录页按月分组并显示完成、跳过、失败统计
- 失败原因写入记录：登录已过期、HTTP 500 等直接显示在当天，首页状态同步显示「今日失败」
- 更新弹窗显示安装包大小与本版改动，移动网络下提醒切换到 WiFi
- 新增「跳过这个版本」，同一版本不再重复提示
- 下载完成后校验 Release 附件的 SHA-256
- 镜像列表支持远程更新，线路失效无需等待新版本
- 设置 → 其他新增配置导出与导入：定时窗口、分享开关、最近任务隐藏、外观打包为文本，不含账号凭据与设备标识
- 首次进入首页时，若有权限未开启，提醒一次并提供「去设置」入口

### 修复

- 系统字体放大到 2 倍时，任务卡片状态文字被裁切、日期换行挤乱状态
- 登录页固定文案「这台机器没有卡」对插卡设备不成立

### 安装

下载 `app-release.apk` 覆盖安装；1.4.x / 1.5.x 签名相同，无需卸载。

### 校验

SHA-256 见附件 `app-release.apk.sha256`。
