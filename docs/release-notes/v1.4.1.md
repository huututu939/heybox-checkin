## 盒签 v1.4.1

### 工程

- 新增 tag 触发的发布流水线：签名打包、`apksigner` 校验、`versionCode` / `versionName` 与 tag 核对、生成 SHA-256、自动创建 Release
- 新增 Android CI：每次推送运行单元测试与 `assembleDebug`
- README 重写为面向使用者的版本，补充真机截图
- 版本号提升至 1.4.1，功能与 1.4.0 相同，用于验证发布流水线

### 安装

下载 `app-release.apk` 覆盖安装；已装 1.4.0 可直接升级，签名相同。从 debug 包切换需先卸载，会丢失登录态与历史。

### 校验

SHA-256 见附件 `app-release.apk.sha256`。
