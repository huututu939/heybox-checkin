## 盒签 v1.4.1

应用功能与 v1.4.0 相同，本次只提升版本号，用于验证「推 tag 自动出签名包」的发布流水线。

### 安装

1. 下载 `app-release.apk`
2. 允许「安装未知来源应用」后侧载
3. 已装 v1.4.0 的用户可直接覆盖升级（签名相同）

从 debug 包换过来需要先卸载，会丢登录态与历史。

### 校验

```text
SHA-256: 8e809c2e5c360d93095266a2af841e1bfabc6c39fbece908c118ed2d7529ca87
```

- 新增 Android CI：每次推送跑单元测试与 `assembleDebug`
