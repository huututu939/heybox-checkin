## 盒签 v1.5.4

两件事：把「应用内更新」的授权顺序理顺了，再把界面上重复的说明删了一轮。

### 修复：不再白下一次

- **先要权限，再下载**：点「应用内更新」时先确认系统允许「盒签」安装应用。没权限就直接带去开关，一个字节都不下
- **给完权限回来自动继续**：从系统设置回到 App，会接着下载或直接弹出安装，不用再点一次
- **已下载的包会复用**：下好的 `app-release.apk` 留在缓存里，如果中途 App 被系统重建、弹窗重新打开，直接进入「已经下好了，点安装」，不会重复下载 8 MB

### 界面：少说，多看

- 删掉 7 处重复或可有可无的说明：执行时段下面那段随机说明、最近任务隐藏的两行解释、值守里「系统读不到这个开关」、页脚的权限提示和「重登只在登录过期时使用」、「每日四件」右侧的「今天」、「随机窗口」标签
- 值守四行换成图标（铃铛 / 电池 / 闹钟 / 电源），**颜色就是状态**：绿=就绪、橙=待处理、灰=要自己去确认；就绪时不再挂一句「已就绪」
- 「关于 / 导出 / 导入 / 退出」也配了图标，退出用的是门 + 箭头，和自启动的电源符号区分开
- 记录页顶部只留总量，跳过和失败交给每月的分组行；完成记录第二行只留时间，没记录的那天不再占两行
- 设置页去掉右上角「1/3 权限就绪」角标（和值守里的图标重复）和卡片里的版本号（关于页有）

### 安装

1. 下载 `app-release.apk`，或在 1.5.3 的 App 里点「检查更新」
2. 1.4.x / 1.5.x 可直接覆盖，签名相同

### 校验

```text
SHA-256: 见 Release 附件 app-release.apk.sha256
```
