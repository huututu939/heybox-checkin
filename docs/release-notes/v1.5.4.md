## 盒签 v1.5.4

### 优化

- 应用内更新改为先确认安装权限再下载，没权限时不再白下载 8 MB
- 从系统设置授权后回到 App，自动继续下载或安装，无需再次点击
- 已下载的安装包会复用，App 被系统重建后也不会重复下载
- 移除 7 处重复说明：执行时段说明、最近任务隐藏说明、「系统读不到这个开关」、页脚权限提示、「重登只在登录过期时使用」、「每日四件」的「今天」、「随机窗口」标签
- 值守条件改为图标展示，颜色即状态：绿=就绪、橙=待处理、灰=需手动确认
- 关于、导出、导入、退出四项增加图标
- 记录页顶部只保留总量，跳过与失败统计移入按月的分组行
- 设置页移除「1/3 权限就绪」角标与卡片内版本号

### 安装

下载 `app-release.apk` 覆盖安装；1.4.x / 1.5.x 签名相同，无需卸载。

### 校验

SHA-256 见附件 `app-release.apk.sha256`。
