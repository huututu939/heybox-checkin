## 盒签 v1.5.2

### 新增

- 打开 App 自动检查更新，有新版本时弹窗提示；网络异常时不打扰

- 应用内更新：直接下载并调起系统安装器，覆盖安装后登录态、历史与定时设置保留

- 下载镜像：内置 gh-proxy.com、ghproxy.net、ghfast.top 等多个加速线路，下载前并发探测并自动选择最快一条

- 退出登录增加二次确认，明确提示将清除登录态、签到历史与定时设置

### 优化

- 「关于 → 检查更新」与应用内更新共用同一弹窗，可选应用内安装或跳转浏览器

### 安全

- 安装前比对下载包与本机应用签名，不一致则取消安装

- 下载内容校验 APK 文件头，避免镜像返回网页内容时交给安装器

### 安装

下载 `app-release.apk` 覆盖安装；1.4.x / 1.5.x 签名相同，无需卸载。

### 校验

SHA-256 见附件 `app-release.apk.sha256`。
