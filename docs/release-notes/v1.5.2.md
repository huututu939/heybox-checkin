## 盒签 v1.5.2

这一版把「更新」这件事做完整了：打开就检查，能直接装，装不上还能换线路。

### 新增

- **打开 App 自动查一次**：进首页时对比 GitHub 上的最新 Release，有新版就弹窗；网络不通或限流时静默，不打扰
- **应用内更新**：弹窗里可以直接下载 `app-release.apk` 并交给系统安装器，覆盖升级后登录态、历史、定时设置都在。首次使用需要允许「盒签」安装未知应用
- **下载走最快线路**：直连 GitHub 之外内置了 gh-proxy.com、ghproxy.net、ghfast.top 等几个加速镜像，下载前并发探测、按首字节延迟选最快的一条，某条失败自动换下一条
- **退出登录确认**：会提示「清掉登录态、签到历史和定时设置，自动签到也会停下」，不再误触即退

### 安全

- 镜像只负责搬运，装包前会比对下载包与本机应用的签名，不一致直接取消安装；系统安装器本身还会再校验一次
- 下载内容会先确认是 APK（ZIP 头），避免镜像回一页 HTML 时交给安装器

### 用法

「关于盒签 → 检查更新」也走同一个弹窗，两路任选：应用内更新，或者跳浏览器下载。

### 安装

1. 下载 `app-release.apk`
2. 允许「安装未知来源应用」后侧载
3. 1.4.x / 1.5.x 可直接覆盖，签名相同

### 校验

```text
SHA-256: 见 Release 附件 app-release.apk.sha256
```
